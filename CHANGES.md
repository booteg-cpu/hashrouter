# 82.0.13 — подключение без обязательного файла

- Установщик выводит IP/домен, порт API, ключ и SHA-256 отпечаток TLS-сертификата.
- sbp-connection.json создаётся только по явному --export-connection; ранее
  созданный файл, ключ, сертификаты, конфигурация и задания сохраняются.
- Добавлен python -m hash_router --version.
- Для подключения без файла клиент должен поддерживать закрепление сертификата
  и независимую сверку отпечатка до отправки ключа. SBP 82.0.11 пока использует
  прежний импорт CA; исходники SBP в этот репозиторий и выпуск не включены.
- Движок Stratum и API маршрутизации не менялись.

# 82.0.12 — отдельный серверный репозиторий

- Удалены Windows-приложение SBP, старые сборки, клиентские адаптеры MRR,
  их тесты и документы.
- Оставлены hash_router, Debian-установка и серверные тесты.
- Добавлен запуск из корня: sudo bash install-router.sh.
- Из комплексного теста удалён только клиентский сценарий продаж MRR;
  серверные сценарии сохранены.
- Движок и формат API не менялись.

Публичный комплект должен публиковаться с чистой историей: прежняя история
смешанного репозитория и релиз с архивом SBP остаются закрытыми.
