# 82.0.24 — путь заданий/шар и автоподстановка VPS

- INFO-диагностика первых трёх событий каждого этапа на соединение: input_work_sent, input_submit_received, share_forward_attempt, upstream_share_result, input_submit_rejected. Отправка означает завершённую запись в сокет, не подтверждение получения клиентом; forward_attempt не обещает доставку пулу.
- input_flow_summary раз в 30 секунд при опросе статуса и при закрытии авторизованного входа: накопленные задания, submit, попытки передачи, принятые/отклонённые/локально отклонённые и неизвестные исходы. Возраст последней отправки/submit добавляется только при наличии события. Output summary включает сложность. Сырые задания, nonce и реквизиты не записываются.
- Установщик подставляет сохранённые public_host/control_port. При первой установке ищет глобальный IP по SSH_CONNECTION, маршруту и локальным интерфейсам, без обращений к внешним сервисам. При неопределённом/неоднозначном адресе требуется ручной ввод. Найденный адрес предлагается для подтверждения; порт по умолчанию 8443. Сохранённые настройки/ключи/сертификаты не заменяются.
- Проверка: 83 серверных офлайн-теста OK; после уточнения валидации повторно 12 тестов подключения OK.
- Локальные тесты не подтверждают отсутствие idle на живом VPS: нужен новый журнал после обновления.

# 82.0.23 — SHA256 version-rolling по BIP310

- SHA256 upstream согласует version-rolling перед subscribe; старые пулы, закрывающие неизвестный запрос, повторно подключаются обычным способом без расширения.
- Вход получает пересечение запрошенной маски с масками готовых выходов. Без готовых совместимых выходов поддержка не заявляется; minimum bit count проверяется как число, но не служит причиной отключения при меньшей доступной маске.
- Шестой параметр submit проверяется по действующей маске. При преобразовании в маску upstream сохраняются неизменяемые входом биты исходной версии задания. Обычный клиент продолжает отправлять пять параметров.
- Смена маски upstream инвалидирует старые задания; вход получает обновлённую маску перед новой работой. Выход без согласованного расширения не получает шары клиента с version-rolling.
- INFO: output_version_rolling и input_configure_result показывают поддержку и маску без реквизитов. Scrypt не меняет порядок подключения.
- Проверка: 78 офлайн-тестов; живые VPS/MRR/ASIC пока не проверены.
