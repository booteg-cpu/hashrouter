# 82.0.19 — подробная диагностика и API журналов

- Структурированные события соединений, авторизации, конфигураций, ошибок и сводок выходов каждые 30 секунд.
- DEBUG: задания, сложность, переключения выходов и результаты шар со временем ответа.
- Авторизованные HTTPS GET /v2/logs и PUT /v2/logging для SBP.
- Ограниченные буфер, очередь записи и ротация файлов; восстановление хвоста, курсоры и явные пропуски. Запись на диск отделена от Stratum.
- Реквизиты и сырые протокольные сообщения не записываются; задания сохраняются.
- See LOGGING.md. Install the server update separately; publishing does not change a running VPS.

# 82.0.15 — заметные реквизиты после обновления

- После успешного запуска службы и настройки firewall установщик повторно
  показывает действующие IP/домен, порт API, адрес, ключ и отпечаток сертификата.
- Блок отделён рамкой; заголовок и реквизиты выделены цветом в терминале.
  Ключ занимает отдельную строку, отпечаток — две строки по 16 байт.
- NO_COLOR или перенаправление вывода отключают ANSI-выделение.
- Промежуточная настройка работает с --quiet и не выводит ключ до запуска службы.
- Повторная установка сохраняет прежние реквизиты, настройки и задания.

# 82.0.14 — исправление прав службы

- Исправлена ошибка runuser: Permission denied при запуске Python из .venv.
  umask 027 оставлял каталоги окружения недоступными группе службы.
- После установки зависимостей окружение получает группу hash-router и права
  чтения/прохода/исполнения для этой группы, без записи. Доступ остальных убран.
  Группа символьных ссылок меняется без изменения системного Python.
- Повторная установка исправляет права существующего окружения. Ключи, TLS,
  конфигурация, задания и права /etc/hash-router не заменяются этим исправлением.
- Автоопределение публичного IP остаётся запланированным отдельным изменением;
  срочное исправление установки его не включает.

# 82.0.13 — подключение без обязательного файла

- Установщик выводит IP/домен, порт API, ключ и SHA-256 отпечаток TLS-сертификата.
- sbp-connection.json создаётся только по явному --export-connection; ранее
  созданный файл, ключ, сертификаты, конфигурация и задания сохраняются.
- Добавлен python -m hash_router --version.
- Для подключения без файла клиент должен поддерживать закрепление сертификата
  и независимую сверку отпечатка до отправки ключа. SBP 82.0.11 пока использует
  прежний импорт CA; исходники SBP в этот репозиторий и выпуск не включены.
- Движок Stratum и API маршрутизации не менялись.

# 82.0.12 — отдельный серверный репозиторий

- Удалены Windows-приложение SBP, старые сборки, клиентские адаптеры MRR,
  их тесты и документы.
- Оставлены hash_router, Debian-установка и серверные тесты.
- Добавлен запуск из корня: sudo bash install-router.sh.

смешанного репозитория и релиз с архивом SBP остаются закрытыми.
