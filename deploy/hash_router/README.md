# Debian Hash Router 82.0.14

Debian 12/13, Python >=3.11. Из корня репозитория:

```bash
sudo bash install-router.sh
```

Укажите публичный IP/домен из панели VPS и порт HTTPS API (обычно 8443).
Установщик создаёт ключ и TLS-сертификат, выводит адрес, порт, ключ и SHA-256
отпечаток серверного сертификата, проверяет конфигурацию и запускает службу.
Файл sbp-connection.json по умолчанию не создаётся и не требуется серверу.

Клиент с поддержкой закрепления сертификата использует IP, порт и ключ.
Перед передачей ключа сверяйте отпечаток с выводом установщика через доверенное
SSH-соединение. Сохранённый отпечаток проверяется при каждом подключении;
после замены сертификата необходимо повторное подтверждение.
Нельзя получать отпечаток и автоматически доверять ему без независимой сверки.

SBP 82.0.11 пока использует CA-файл. Для совместимости доступен явный экспорт:

```bash
sudo python3 deploy/hash_router/setup_connection.py --host YOUR_VPS_IP --export-connection
```

Перенесите /etc/hash-router/sbp-connection.json по SSH/SFTP и импортируйте его в
SBP. Файл содержит ключ, храните его закрыто. Ключи и конфигурация при повторном
запуске не заменяются; старый файл экспорта не удаляется. Без --export-connection
повторный запуск показывает действующие адрес, порт, ключ и отпечаток.

Настройки алгоритмов и маршрутизации передаёт SBP через API v2. Стартовые
параметры службы, ключ и TLS остаются в /etc/hash-router/config.json, задания —
в /var/lib/hash-router/state.json. Обновление сохраняет их, но останавливает
службу на время установки: подача хэша прервётся.

Откройте в панели VPS показанные TCP-порты (обычно 8443 и 3333–3433).
Установщик добавляет правила только если UFW уже включён.

```bash
sudo systemctl status hash-router
sudo journalctl -u hash-router -n 50
/opt/hash-router/.venv/bin/python -m hash_router --version
```

Серверный сертификат действует 365 дней; продление пока ручное. Новый сертификат
подписывается существующим CA; при закреплении листового сертификата отпечаток
изменится. Закрытый connection-ca.key хранится только на VPS.
Установка на настоящем Debian/systemd и живые ASIC этим выпуском не проверялись.
