# Debian Hash Router 82.0.12

Debian 12/13, Python >=3.11. Из корня репозитория:

```bash
sudo bash install-router.sh
```

Укажите публичный IP/домен и порт HTTPS API (по умолчанию 8443).
Установщик создаёт ключ, сертификат и `/etc/hash-router/sbp-connection.json`,
проверяет файлы и запускает службу. Повторная установка сохраняет ключ,
настройки и `/var/lib/hash-router/state.json`. На время обновления служба
останавливается: учитывайте перерыв в подаче хэша.

Скопируйте файл подключения через своё SSH-соединение и импортируйте его в
SBP → Hash Router → «Подключение к роутеру». Нажмите «Проверить и подключить».
Адрес и ключ становятся общими, порты алгоритмов SBP получает автоматически.
Сертификат из файла используется только для этого соединения; проверка HTTPS
и имени сервера остаётся включённой. Файл содержит ключ доступа, храните его закрыто.

В панели VPS откройте показанные установщиком TCP-порты (обычно 8443 и 3333–3433).
Установщик добавляет правила, если UFW уже включён. Иные firewall автоматически
не меняются. При ошибке запуска проверьте:

```bash
sudo systemctl status hash-router
sudo journalctl -u hash-router -n 50
```

Серверный сертификат действует 365 дней. Продление пока ручное: новый сертификат
нужно подписать существующим CA и перезапустить службу. Сохраняйте закрытый
`connection-ca.key` только на VPS; в SBP передаётся открытый сертификат CA.
Для старой установки с собственным сертификатом пути сохраняются; пользователь
службы должен иметь доступ к сертификату и ключу.

Движок/API не изменены относительно 81.6.123. Установка Debian/systemd и живые
ASIC в этом выпуске не проверялись; локально проверены HTTPS и офлайн-имитаторы.
